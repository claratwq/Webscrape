# Webscrape

This folder documents the methods used to webscrape public housing information as part of creating a database of houses and their housing index in Singapore. 

Other sources of data excluded from this work is from data.gov for HDB public housing and public amenities (e.g. schools) 

Methods used are:
1. Webscrapping using selenium
2. Multitreading to increase speed of pulling while websites are being loaded
3. Api calls to onemap
